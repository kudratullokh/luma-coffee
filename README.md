# Вақтинчалик Siberian каталоги (gh-pages)

Бу шохча (branch) фақат Siberian Wellness каталоги мини-аппи учун:
https://kudratullokh.github.io/luma-coffee/siberian/

LUMA Coffee сайти `main` шохчасида турибди, унга тегилмаган.
Алоҳида `siberian-catalog` репоси очилгач, каталог ўша ерга кўчирилади ва бу шохчани ўчириб юбориш мумкин.

- `siberian/index.html` — мини-апп
- `siberian/products.json` — маҳсулотлар ва нархлар (нарх ўзгарса, шу файлни янгилаш кифоя)
- `siberian/bot.tar.gz` — Telegram бот коди: Colab ноутбуки ишга тушганда шу ердан янгиланади
- `siberian/fonts/` — Onest шрифти (SIL Open Font License, `OFL.txt`)
